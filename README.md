# PS-JailBreak — ModLab Mérida

Landing page de **ModLab Mérida**, servicio técnico local en Mérida, Yucatán especializado en la modificación de sistema (jailbreak) de consolas PS4 por software, con opción de instalación de disco interno o externo. Entrega el mismo día o en 24–48 horas, con garantía.

Sitio publicado con GitHub Pages en: https://demoniodeb.github.io/PS-JailBreak/

## Contenido

- `index.html` — página única con toda la estructura, estilos y comportamiento del sitio (hero, servicios, paquetes y precios, zona de atención, preguntas frecuentes y contacto por WhatsApp).
- `assets/` — favicons e ícono para dispositivos Apple (`apple-touch-icon.png`, `favicon-16.png`, `favicon-32.png`, `favicon-48.png`).

## Paquetes de servicio

| Paquete | Descripción | Precio |
|---|---|---|
| Solo Modificación | Modificación de sistema por software | $500 MXN |
| Con Disco Interno | Modificación + instalación de disco interno | desde $1,100 MXN |
| Interno + Externo | Modificación + disco interno y externo | desde $1,750 MXN |

Los precios finales varían según la capacidad de almacenamiento elegida (ver `index.html`).
